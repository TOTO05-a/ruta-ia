# RutaIA — matriz de aceptación y evidencia

Esta matriz convierte la rúbrica, los casos académicos y los criterios del Registro de Decisiones en verificaciones reproducibles. **Implementado** significa que existe código; solo **Probado** requiere salida reproducible de ejecución.

## Evidencia ejecutada

**Última actualización tras seed 011 (4 nov 2026):** PostgreSQL tiene 38 cursos activos y Qdrant 38 UUID idénticos (0 faltantes, 0 sobrantes). Los seeds 001–011 mantienen 37 cursos con fuente HTTPS; uno adicional administrado desde la app carece de `source_url`. ## Cobertura actual de las consultas académicas obligatorias

Se generó cada embedding con `bge-m3` local; el calibrador replica el texto exacto del indexador y mide los 38 cursos activos. En la ejecución posterior al seed 011, con 22 casos etiquetados, el máximo tercer score fuera de dominio fue `0.5292` y el mínimo tercer score positivo relevante `0.5396`, ventana `0.5292–0.5396`; se conserva `.535`, con margen estrecho. Esta ejecución supersede las cifras históricas `0.4569–0.5740`, cuya diferencia no puede atribuirse sin el snapshot usado entonces. Las siete preguntas académicas obtuvieron 1, 1, 2, 1, 3, 3 y 0 resultados sobre el umbral. IA obtiene tres fuentes pertinentes. La pregunta de seguridad de aplicaciones devuelve tres cursos generales de ciberseguridad/Fortinet; eso no demuestra cobertura específica de seguridad web. La E2E IA histórica usó 35 cursos y confirmó una respuesta con tres ofertas. La medición de similitud no invoca al LLM ni sustituye la E2E.
